menu_book 사용 안내 (Usage Guide)
01
환경 변수 구성

`.env` 파일을 생성하고 발급받은 관리자 토큰을 입력합니다. 보안을 위해 해당 파일은 버전 관리 시스템에서 제외되어야 합니다.

02
연결 테스트 실행

콘솔 터미널에서 `ping` 명령어를 통해 게이트웨이 서버와의 정상적인 통신 상태를 확인합니다. 타임아웃 발생 시 네트워크 정책을 검토하세요.

03
초기 권한 설정

시스템 개요 패널에서 '권한 부여' 섹션으로 이동하여 첫 번째 서비스 계정의 접근 범위를 최소 단위로 할당합니다.
