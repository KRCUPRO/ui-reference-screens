Quickstart

A brief introduction to querying the Marginalia archive. This guide will walk you through setting up your first request to retrieve historical indices.

1. Initialize the client

Begin by instantiating the archival client in your environment. Ensure your authentication tokens are properly configured in your environmental variables.

python 
from marginalia import ArchiveClient

# Initialize with default environment credentials
client = ArchiveClient()

# Verify connection
status = client.ping()
print(f"Archive status: {status}")

2. Formulate a query

Construct your query parameters. The system is optimized for precise temporal and topical constraints. Using the IndexSearch protocol ensures the lowest latency.

3. Execute the request

Submit the query to the primary ledger. Results are paginated by default; refer to the Pagination guide for handling large response sets.

json 
{
  "query": {
    "topic": "typographic_history",
    "era": "19th_century",
    "limit": 10
  },
  "context": "strict"
}
